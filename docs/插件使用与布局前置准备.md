# AD Component Placer 使用与布局前置准备

## 1. 适用范围

AD Component Placer 用于以一个或多个中心器件为锚点，自动整理其 Component Class 内的外围器件。它适合未布线或仅完成局部预布局的 PCB，尤其适合 MCU、FPGA、显示模组、电源子模块等“中心器件 + 外围器件”结构。

插件会保持锁定器件和所选中心器件的位置、方向不变；移动其余选中 Class 成员，并在写回前检查器件间距与包围框碰撞。

> 当前版本不读取 PCB 板框、Keepout、走线、过孔或 AD 原生 Room 作为求解约束；也不自动布线。它们仍必须在运行前后由设计人员检查。

---

## 2. 使用前总检查表

在运行插件前，建议逐项完成以下准备：

- [ ] 原理图已完成、注释（Annotate）稳定、工程已编译且无关键 ERC 问题。
- [ ] PCB 已通过 ECO 与原理图同步，所有目标器件已有正确封装、焊盘和网络。
- [ ] 目标 Component Class 已建立并同步到 PCB。
- [ ] 每个 Class 的中心器件已明确；优先在原理图设置 `CenterComponent` 参数。
- [ ] PCB 板框、开槽、禁放区和关键结构区域已定义并经人工复核。
- [ ] 连接器、安装孔、屏蔽罩、按键、显示器、散热/大功率器件等结构相关物料已经预布局并锁定。
- [ ] 关键电气拓扑已确定，例如 DC/DC 电流环路、晶振、DDR/高速接口、模拟敏感区。
- [ ] 已保存 PCB，并保留可回退的工程副本或 Git 提交。

---

## 3. 原理图和 Component Class 准备

### 3.1 先完成原理图

运行布局前，原理图至少应满足以下条件：

1. 位号已经稳定。插件通过 PCB 位号与原理图的物理位号匹配中心器件。
2. 目标器件的封装、焊盘和网络已确认。缺失网络会降低 HPWL 优化的意义。
3. 原理图已编译，并已执行 ECO，将 Component Class 和器件成员关系同步至 PCB。
4. 不要在布局过程中更改原理图位号、中心参数或 Class 成员；插件在写回前会重新核验这些数据，不一致时会拒绝应用结果。

### 3.2 正确划分 Component Class

一个 Class 应当代表一个可局部收拢的功能单元，例如：

- `MCU_CORE`：MCU、去耦电容、复位/启动电阻、晶振及其负载电容；
- `BUCK_5V`：控制器、电感、二极管/MOS、输入输出电容和反馈分压；
- `LCD`：显示连接器、显示驱动及局部去耦；
- `USB`：USB 连接器、ESD、共模电感、串联电阻和收发器附近元件。

避免把整板所有器件放入同一个 Class，也避免让同一个可移动器件同时属于多个将被选中的 Class。后者会导致插件拒绝开始，以避免重复移动。

### 3.3 选择中心器件

中心器件是该 Class 的布局锚点，通常应为：

- MCU、FPGA、SoC、显示模组主芯片；
- DC/DC 控制器或功率主器件；
- 不能再随意移动的主连接器或模块。

推荐在同一 Class 的所有原理图成员上设置相同参数：

```text
CenterComponent = U1
```

多个中心可用空格分隔，例如：

```text
CenterComponent = U1 U2
```

参数有效时，插件自动采用这些中心；参数缺失、冲突或与 PCB 位号不匹配时，界面才会允许手动选择。中心必须是该 Class 的成员。

### 3.4 已手工定位的中心器件

如果中心芯片、连接器或模块的位置已由机械、外观或信号路径决定，应先在 PCB 上完成手工放置并锁定（`Moveable = False`）。

此时插件将：

- 保持中心位置与方向不变；
- 让该 Class 的外围器件围绕中心优化；
- 将该 Class 标记为 `follow_locked_center`，不施加 ClassPlacer Room/搜索边界限制；
- 继续执行与其他器件的碰撞和间距检查。

这适合已经固定主芯片位置、但仍需要自动整理去耦、阻容和小外围件的场景。

## 4. PCB 物理与结构准备

### 4.1 板框和禁放区

应在 PCB 中先完成：

- Board Shape、拼板边、V-cut、开槽和孔位；
- 连接器开口、显示窗、螺丝孔、卡扣、屏蔽罩和外壳干涉区域；
- 器件禁放区、铜皮禁布区、工艺边和测试区域；
- 高度限制、单面贴装限制和装配边界。

但必须注意：**当前插件不会把板框和 Keepout 当成自动布局障碍。** 定义它们是为了让工程完整、便于人工检查和后续 DRC，而不是让本版本求解器自动避让。

因此，在禁放区附近使用插件时，请采用以下任一策略：

1. 先手工放置并锁定该区域周围的关键器件，仅让插件整理安全区域内的局部 Class；或
2. 在插件完成后人工检查板框和禁放区，必要时手工调整并锁定；或
3. 暂不对靠近复杂机械边界的 Class 使用自动布局。

### 4.2 必须预布局并锁定的物料

下列器件通常由结构、外观、装配或散热决定，应在运行前预布局并锁定：

- USB、HDMI、RJ45、DC 插座、按键、LED、天线座等接口件；
- 显示器、蜂鸣器、开关、电池座、马达座、继电器；
- 安装孔、定位孔、屏蔽罩、散热器、散热焊盘附近的大件；
- 变压器、电感、大电容、功率器件及有明确散热铜皮要求的器件；
- 与外壳开孔、丝印窗口、面板按键位置直接相关的器件。

锁定件会参与避让，但插件不会改变它们的位置或方向。

### 4.3 层面与装配限制

运行前确认目标 Class 的中心所在层。插件可选择 `keep`、`top` 或 `bottom`，但中心和锁定件不会翻面；指定目标层时，所有选定中心必须本来就在该层。

对于以下情况，建议先人工决定层面与位置，再运行插件：

- 单面贴装或回流工艺限制；
- 连接器、屏蔽罩、散热器造成的高度/面别限制；
- 模拟、射频或高速区域要求的层面分区；
- 需要在某一面保留测试点、标签或装配空间的区域。

## 5. 电气布局前置判断

插件以类内网络的 HPWL 和中心聚集为主进行优化。使用前仍需要设计人员明确以下电气关系：

### 5.1 去耦与电源

- 去耦电容应属于对应 IC 的 Class，并按电源脚位置人工确认；
- 大电流 DC/DC 的输入电容、开关管、二极管/同步管、电感和输出电容应先按数据手册明确关键回路；
- 对开关电源、栅极驱动、采样、反馈等敏感环路，不要只依赖自动布局结果，必须人工审核回路面积和电流路径。

### 5.2 高速、时钟和差分信号

- 晶振和负载电容建议与主芯片放在同一 Class，且先确认是否需要强制手工位置；
- DDR、USB、PCIe、MIPI、以太网等高速网络需要预先定义阻抗、等长、差分和参考平面策略；
- 插件不会自动进行长度匹配、阻抗控制、差分对耦合或自动布线，应在布局后继续使用 AD 规则与交互布线完成。

### 5.3 模拟、射频与隔离

- 模拟前端、ADC/DAC 参考、RF 匹配网络和隔离边界应预先确定区域；
- 不建议让自动布局跨越模拟/数字、强弱电、安规隔离等边界；
- 对关键器件可先手工布局并锁定，再让插件处理低风险外围件。

## 6. 运行步骤

1. 保存 PCB，并确认激活的是已打开工程中的目标 `.PcbDoc`。
2. 在 Altium Designer 中运行 `ClassPlacer.pas` 的 `RunClassPlacement`。
3. 在选择窗口中勾选本次要处理的 Component Class。
4. 检查每个 Class 的中心器件和目标层：
   - 有效的 `CenterComponent` 参数会直接显示；
   - 参数异常时，手动选择一个或多个中心；
   - 需要翻面时选择 `top` 或 `bottom`，否则使用 `keep`。
5. 设置器件间距（默认 `12 mil`）和每类计算时限（默认 `5 秒`）。
6. 点击“布局并自动应用”。若任一选中 Class 无解或取消，整批不会部分写回。
7. 等待 AD 自动重新核验并一次性写回结果。PCB 会保持未保存状态，便于检查或使用 `RestoreClassPlacement` 回退。

---

## 7. 布局后必须检查

自动完成不等于可直接投产。至少执行：

- [ ] 检查所有中心、连接器和锁定结构件是否仍在预期位置。
- [ ] 检查去耦电容到对应电源脚的相对位置和回流路径。
- [ ] 检查 DC/DC、晶振、高速接口、模拟/RF 和隔离区的人工规则。
- [ ] 检查器件是否越过板框、进入 Keepout、遮挡开孔或违反高度限制。
- [ ] 运行 Altium DRC，并检查间距、短路、封装重叠、丝印、装配和机械规则。
- [ ] 根据需要进行交互布线、长度匹配和铜皮规划。
- [ ] 审核本次任务目录中的 `report.json`、`rooms.json` 和恢复文件后，再保存 PCB。

`rooms.json` 是审计清单；当前版本不直接在 AD 中创建或改变原生 Room。对锁定中心的 Class，其中会记录 `room_enabled=false` 和 `follow_locked_center=true`。

---

## 8. 何时不应直接使用自动布局

以下情形建议先人工完成关键布局，或只对小范围外围件使用插件：

- 板框、Keepout 或机械开孔非常紧凑；
- 已经完成大量布线；
- 需要严格控制高速走线拓扑、长度、阻抗或差分耦合；
- 存在安规隔离、RF、敏感模拟或大电流热设计要求；
- Class 中包含不应移动的大型结构件但尚未锁定；
- 中心器件或 Class 成员关系尚未确定。

先确保结构与关键电气约束正确，再使用插件处理规则明确、可局部收拢的外围器件，通常会得到最稳定的结果。
